# Contributing

Public proposals should describe their technical problem, evidence and reproducible steps. Never put secrets, personal data, unpublished client information or private knowledgebase files in public issues. Source claims need links and review. Sensitive security reports must not disclose exploit details publicly; use an approved private route once available.

## GitHub workflow safety

Contributions that create or change `.github/workflows/*` must include human approval, the local policy scanner results, resource budget and a valid restricted-CI purpose. Recurring AI agents, web crawling and business automation must run outside Actions. No Github Pages commercial deployment is permitted by default. See [AGENTS.md](AGENTS.md).
